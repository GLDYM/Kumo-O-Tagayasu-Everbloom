## 介绍 Introduction

***命题：如何用现代的整合包叙事语言讲述过去的模组？***

> 多年过去，这个世界被摩隆破坏的生态与文明已经恢复，我们决定再次造访这个世界，访察这个世界的科技与文明；但是这个世界的运行法则似乎发生了极大变化……

《耕云钓月：永绽》是一款将 1.12.2 版本模组与 1.21.1/1.20.1 版本模组结合的综合性整合包。“玩家”将作为理想境的理境访察使造访这个世界，访察这个世界的科技与文明，并寻找世界运行法则发生极大变化的真相。

### 📚历久弥新，融汇贯通

通过将大量 1.12.2/1.20.1 版本模组的内容迁移到 1.21.1 并进行调整，《耕云钓月：永绽》得以将新旧版本的模组纵向连接；深度联动附属模组、模组的内置联动代码与 KubeJS 魔改则将这些模组横向连接。“玩家”将以机械动力为主要研究工具，研究并**<u>大规模复现</u>**多个时代的文明科技：

- ISS、农夫乐事、森罗物语等现代文明科技（高版本模组）；
- 月、理想境等古代文明科技（低版本模组）；
- 超级源方块、机动突破等理境文明科技（轮椅模组）；
- 笼中生物、魔法食事等横向连接文明科技（联动附属模组）；
- 深渊奏鸣、月的调整内容等纵向连接文明科技（纵向连接附属模组）。

当然，这意味着绝大部分玩家将面临完全不熟悉的模组，以及复杂而抽象的材料生产方法。尽管《耕云钓月：永绽》提供了暴力的轮椅模组、大量的任务书奖励、从零开始（包括邪道的）完整模组指引以及部分产线的参考答案，但若不看参考答案，这个世界对“玩家”仍将是不小的挑战。

### 🌠长时间多人游玩体验优化

但这不意味着这个整合包放弃了休闲玩家。整合包延续了前代的风格，对长时间游玩与多人游玩进行特别优化：

- 地形&结构：使用 Tectonic V2 作为地形模组以优化地形，并增加大量机械动力相关结构优化世界生成；
- 建筑特化：增加大量家具模组，并提供建筑师手册任务章节指引建筑；
- 多人互动：体验[偷菜](https://www.mcmod.cn/class/9615.html)的紧张，将爱心料理（或者奇怪的东西？）[喂给其他玩家](https://www.mcmod.cn/class/16577.html)，在聊天框中发送[表情包](https://www.mcmod.cn/class/9111.html)，在家中[播放来自理境的音乐](https://www.mcmod.cn/class/4935.html)；
- 服务端：使用 Github Action 自动构建服务端与客户端，并验证连接可行性，服务端也提供了额外的优化参数与管理模组；

### 💭Q&A

**Q：** 服务端在哪里？

**A：** Curseforge 提供服务端构建包，请参照服务端包内的提示构建服务端。Github 与夸克网盘提供完整服务端。

**Q：** 整合包需要多少内存来运行？

**A：**

单人与客户端建议不低于 6G。测试设备：CPU&核显：i7-1165G7 ＠ 2.80GHz 分辨率：3000x1894

服务端建议不低于 6G，并根据人数与 CPU 性能适当提升。

你可能需要 PCLII 的“启动游戏前进行内存优化”功能来获得足够多的内存，或者参考整合包百科界面的教程使用合适的 JVM 参数。

**Q：** 整合包启动后崩溃怎么办？

**A：** 本整合包需要 Java21 来启动，请确保你的 Java 版本是正确的。如果你额外删改了模组，请排查此问题是否来源于你新安装或删除的模组，如果你没有添加或删除任何模组，请提供崩溃日志并详细说明在崩溃前你做了什么事情。

**Q：** 进入存档后崩溃或提示无效的玩家数据？

**A：** 通常情况下，玩家昵称或游戏路径含有中文可能会导致崩溃，或者是直接关闭游戏或者关闭计算机时未关闭游戏（如拔下电源）等造成强制关闭游戏的情况，又或者是添加或删除模组，可能会导致当前正在游玩中的存档损坏，唯一的解决办法是恢复至上一次的备份。

**Q：** 安卓、Linux、Mac平台适配？

**A：**

Mac&Linux：需要禁用 [IMBlock](https://www.mcmod.cn/class/3358.html) 以正常进入游戏。此外如果需要显示 [WATERFrAMEs](https://www.mcmod.cn/class/14735.html) 模组的图片与视频，你需要额外安装 VLC。

安卓：不支持安卓设备。
